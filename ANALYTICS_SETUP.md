# 📊 Настройка аналитики и метрик

## Текущее состояние

В проекте уже настроены следующие системы аналитики:

### ✅ Vercel Analytics
- **Статус:** Активен автоматически
- **Функции:** Анонимная аналитика производительности
- **Cookies:** Не использует
- **GDPR:** Соответствует (анонимные данные)

### ⚠️ Google Analytics
- **Статус:** Настроен, но требует GA_ID
- **Функции:** Детальная аналитика поведения пользователей
- **Cookies:** Использует (требует согласия)
- **GDPR:** Соответствует (с cookie consent)

## 🔧 Настройка Google Analytics

### 1. Создание GA4 свойства

1. Перейдите в [Google Analytics](https://analytics.google.com/)
2. Создайте новое свойство GA4
3. Выберите "Веб-сайт"
4. Введите URL сайта: `https://aethr.ru`
5. Скопируйте **Measurement ID** (формат: `G-XXXXXXXXXX`)

### 2. Настройка переменных окружения

Добавьте в Vercel Dashboard → Project → Settings → Environment Variables:

```bash
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
```

### 3. Проверка работы

После добавления переменной:
1. Перезапустите проект
2. Откройте сайт в режиме инкогнито
3. Примите cookies в баннере
4. Проверьте в GA4 Real-time отчеты

## 🍪 Cookie Consent

### Как это работает

1. **При первом посещении:** Показывается баннер согласия
2. **Пользователь выбирает:**
   - "Принять все" → Загружается Google Analytics
   - "Отклонить" → Только Vercel Analytics
   - "Настройки" → Пока что принимает все

3. **Согласие сохраняется** в localStorage на 1 год
4. **Google Analytics загружается** только после согласия

### Управление согласием

Пользователи могут:
- Изменить настройки через браузер
- Очистить localStorage для повторного показа баннера
- Обратиться к администратору для сброса

## 📈 Просмотр метрик

### Vercel Analytics
- **Где:** Vercel Dashboard → Project → Analytics
- **Что показывает:** Page views, visitors, performance
- **Доступ:** Только владелец проекта

### Google Analytics
- **Где:** [analytics.google.com](https://analytics.google.com/)
- **Что показывает:** Детальная аналитика, поведение, конверсии
- **Доступ:** Настраивается через GA4

## 🔒 GDPR Compliance

### Что мы делаем для соответствия

1. **Cookie Consent Banner** - явное согласие пользователя
2. **Условная загрузка** - аналитика только с согласия
3. **Прозрачность** - подробная политика конфиденциальности
4. **Права пользователей** - возможность отозвать согласие

### Типы данных

| Тип | Vercel Analytics | Google Analytics |
|-----|------------------|------------------|
| IP-адрес | Анонимизирован | Анонимизирован |
| Cookies | Не использует | Использует (с согласия) |
| Персональные данные | Нет | Нет |
| Геолокация | Страна/регион | Город (приблизительно) |

## 🚀 Рекомендации

### Для максимальной эффективности

1. **Настройте цели в GA4:**
   - Отправка формы заявки
   - Переходы на страницу контактов
   - Время на сайте

2. **Используйте UTM-метки** для отслеживания источников трафика:
   ```
   https://aethr.ru?utm_source=telegram&utm_medium=social&utm_campaign=announcement
   ```

3. **Мониторьте производительность:**
   - Core Web Vitals в GA4
   - Vercel Analytics для скорости загрузки

### Для соответствия GDPR

1. **Регулярно обновляйте** политику конфиденциальности
2. **Ведите журнал** согласий (опционально)
3. **Обучайте команду** правилам обработки данных
